# 🐄 COWSMART – ระบบบริหารจัดการฟาร์มโคเนื้ออัจฉริยะ

**COWSMART** คือระบบจัดการฟาร์มวัวเนื้อแบบครบวงจร เจ้าของฟาร์มใช้ **แอปมือถือ** บันทึกและติดตามข้อมูลวัวรายตัวได้ทั้งหมด ตั้งแต่ประวัติสุขภาพ การผสมพันธุ์ การคลอด น้ำหนัก อาหาร ไปจนถึงต้นทุนและรายรับ-รายจ่ายของฟาร์ม ส่วนผู้ดูแลระบบใช้ **เว็บแอดมิน** จัดการข้อมูลพื้นฐาน ผู้ใช้ ประกาศแจ้งเตือน และฐานความรู้ของ AI ผู้ช่วยหมอวัว

🌐 **เว็บผู้ดูแลระบบ (Live Demo):** [cowsmart.vercel.app](https://cowsmart.vercel.app) (สำหรับบัญชีแอดมินเท่านั้น)

โปรเจกต์นี้แบ่งออกเป็น 3 ส่วนหลัก ได้แก่:

1. **API (Backend)** - สร้างด้วย Laravel
2. **Admin Web (Frontend)** - สร้างด้วย React + Vite
3. **COWSMART App (Mobile)** - สร้างด้วย Flutter

## 🎯 ที่มาและจุดประสงค์

การเลี้ยงวัวเนื้อมีข้อมูลที่ต้องจดจำและติดตามจำนวนมาก เช่น วันผสมพันธุ์ กำหนดคลอด ตารางวัคซีน ประวัติการรักษา น้ำหนักตัว และค่าใช้จ่ายของวัวแต่ละตัว ถ้าจดลงสมุดก็ค้นหาย้อนหลังและสรุปผลได้ยาก COWSMART จึงทำขึ้นเพื่อช่วยให้เกษตรกรเก็บข้อมูลฟาร์มทั้งหมดไว้ในมือถือเครื่องเดียว มีระบบแจ้งเตือนนัดหมายสำคัญ และช่วยวิเคราะห์ต้นทุน มูลค่าวัว และกำไร-ขาดทุนของฟาร์ม เพื่อให้วางแผนการเลี้ยงและการขายได้ดีขึ้น

## ✨ ฟีเจอร์หลัก

### 📱 แอปมือถือ (สำหรับเจ้าของฟาร์ม)
- **บัญชีผู้ใช้** สมัครสมาชิก เข้าสู่ระบบ ลืมรหัสผ่าน (ยืนยันด้วยรหัส OTP ทางอีเมล) แก้ไขข้อมูลส่วนตัว และเปลี่ยนรหัสผ่าน
- **ฟาร์มและโซน** สร้าง แก้ไข และสลับได้หลายฟาร์ม แบ่งโซน/คอก และย้ายวัวเข้า-ออกโซน
- **แดชบอร์ดฟาร์ม** สรุปจำนวนวัว มูลค่ารวมของฟาร์ม กำไร/ขาดทุน จำนวนที่คัดทิ้งในเดือนนี้ และทางลัดไปยังเมนูต่าง ๆ
- **ทะเบียนวัว** เพิ่ม/แก้ไขข้อมูลวัว (เบอร์วัว ชื่อ เพศ ประเภท สายพันธุ์ พ่อ-แม่พันธุ์ วันเกิด วันเข้าฟาร์ม ราคาซื้อ น้ำหนัก รูปภาพ) พร้อมค้นหาและกรองรายการตามเพศ ประเภท และสถานะ
- **รายละเอียดวัวรายตัว** แบ่งเป็นแท็บ
  - *ข้อมูลทั่วไป* อายุ น้ำหนักล่าสุด สถานะสุขภาพ และมูลค่าประเมินตามราคาตลาด
  - *น้ำหนัก* บันทึกน้ำหนัก ดูกราฟแนวโน้มการเติบโต และคำนวณน้ำหนักจากรอบอก (สูตร (รอบอก ซม.)³ ÷ 27,000)
  - *ผสมพันธุ์* บันทึกการผสม (รวมถึงผสมเทียม) ตรวจท้อง/แท้ง คำนวณกำหนดคลอด และบันทึกการคลอด (รองรับลูกแฝด และไปลงทะเบียนลูกวัวต่อได้ทันที)
  - *สุขภาพ* บันทึกการตรวจสุขภาพ ฉีดวัคซีน ให้ยารักษา ถ่ายพยาธิ พร้อมระบุโรค ยา/วัคซีน ปริมาณ หน่วย ค่าใช้จ่าย และรูปภาพ รวมถึงตั้งนัดหมายล่วงหน้า
  - *ค่าใช้จ่าย* สรุปค่าเลี้ยงดูสะสม (ราคาซื้อ ค่าอาหาร ค่ารักษา) เทียบกับมูลค่าประเมินเพื่อวิเคราะห์ความคุ้มค่า
- **โปรแกรมวัคซีนลูกวัว** แนะนำวันฉีดวัคซีนตามเกณฑ์กรมปศุสัตว์จากวันเกิด และตั้งนัดหมายให้อัตโนมัติ
- **จัดการแบบกลุ่ม** บันทึกการรักษา ตั้งนัดหมาย และจำหน่าย/คัดออก (ขาย คัดออก ตาย) ทีละหลายตัวหรือทั้งฟาร์ม พร้อมดูประวัติการจำหน่าย
- **QR Code และ NFC** สร้าง QR Code ประจำตัววัว สแกน QR เพื่อเปิดข้อมูลวัว พิมพ์ QR แบบกลุ่มเป็น PDF และเขียน/อ่านข้อมูลวัวผ่านเหรียญ NFC
- **อาหารสัตว์** บันทึกการให้อาหารตามโซนหรือระบุรายตัว ปริมาณ และมูลค่า พร้อมประวัติการให้อาหาร
- **บัญชีรายรับ-รายจ่าย** บันทึกรายการ สรุปรายรับ รายจ่าย และคงเหลือสุทธิรายเดือนหรือตามช่วงวันที่เลือก
- **ราคาตลาดกลางโคเนื้อ** ดูราคากลางรายสัปดาห์ (ข้อมูลจาก NABC / สศก.) ประวัติราคา และประเมินราคาขายตามน้ำหนักตัว
- **ปฏิทินกิจกรรม** รวมนัดหมายสุขภาพ กำหนดคลอด และกิจกรรมทั่วไปของฟาร์ม พร้อมตั้งเวลาแจ้งเตือนล่วงหน้า
- **การแจ้งเตือน** แจ้งเตือนในแอปและ Push Notification (กำหนดคลอด นัดหมาย กิจกรรม และประกาศจากแอดมิน)
- **หมอวัว CowSmart (AI ผู้ช่วยสัตวแพทย์)** แชตเล่าอาการวัวหรือเลือกคำถามด่วน เพื่อรับคำแนะนำการปฐมพยาบาลและการดูแลเบื้องต้น
- **รายงาน PDF** ส่งออกรายงานภาพรวมฟาร์ม (ทรัพยากร มูลค่าแยกตามสายพันธุ์ สถานะสุขภาพ รายชื่อวัวและมูลค่า) แล้วบันทึกลงเครื่อง แชร์ หรือสั่งพิมพ์ได้
- **ตั้งค่าและช่วยเหลือ** รายงานปัญหา/ข้อเสนอแนะถึงแอดมิน (แนบรูปได้) คำถามที่พบบ่อย และตั้งค่าการแจ้งเตือน

### 💻 เว็บผู้ดูแลระบบ (Admin Web)
- **แดชบอร์ดภาพรวม** จำนวนผู้ใช้ ฟาร์มที่ใช้งาน จำนวนวัวทั้งหมด ลูกเกิดใหม่ สัดส่วนสุขภาพวัว สถิติโรค (Top 5) สายพันธุ์ยอดนิยม (กราฟ) และรายงานปัญหาล่าสุด
- **จัดการผู้ใช้งาน** ค้นหา กรอง เปลี่ยนบทบาท (ผู้ใช้/แอดมิน) และเปิด/ปิดการใช้งานบัญชี
- **ส่งแจ้งเตือน / ประกาศ** ส่งประกาศถึงผู้ใช้ทุกคน (เช่น เตือนภัยโรคระบาด แนะนำโภชนาการ ปิดปรับปรุงระบบ) พร้อมดูตัวอย่างและลบประกาศย้อนหลัง
- **AI ผู้ช่วยหมอ** จัดการชุดคำถาม-คำตอบและคีย์เวิร์ดที่ AI ใช้ตอบ เปิด/ปิดหัวข้อ และทดสอบถาม-ตอบได้ในหน้าเดียว
- **รายงานการใช้งาน** ดูรายงานปัญหา/ข้อเสนอแนะจากผู้ใช้ (พร้อมรูปภาพ) เปลี่ยนสถานะเป็นรอดำเนินการ/แก้ไขแล้ว และจัดการหัวข้อรายงาน
- **ข้อมูลพื้นฐาน** จัดการสายพันธุ์วัว ประเภทวัว โรคและอาการป่วย รายการยา รายการวัคซีน ประเภทกิจกรรม ประเภทนัดหมาย และหน่วยวัด
- **ราคาตลาดกลาง** ซิงก์ราคากลางรายสัปดาห์จาก NABC AgriAPI อัตโนมัติ เพิ่ม/แก้ไขเอง หรือให้ AI อ่านตัวเลขจากรูปภาพรายงานราคา
- **ตั้งค่าการคำนวณวันคลอด** กำหนดระยะเวลาตั้งท้องเฉลี่ย (วัน) ที่ใช้คำนวณกำหนดคลอดในแอป

### ⚙️ ระบบหลังบ้าน (API)
- REST API สำหรับแอปมือถือและเว็บแอดมิน ยืนยันตัวตนด้วย Token (Laravel Sanctum)
- คำสั่งอัตโนมัติ `notifications:generate` ทำงานทุกวันเวลา 08:00 น. (เวลาไทย) เพื่อสร้างแจ้งเตือนกำหนดคลอด นัดหมายสุขภาพ และกิจกรรมในปฏิทิน
- คำสั่ง `market-price:fetch` ดึงราคาโคเนื้อรายสัปดาห์จาก NABC AgriAPI (agriapi.nabc.go.th)

## 👥 ผู้ใช้งานและบทบาท

| บทบาท | ใช้งานผ่าน | สิทธิ์การใช้งาน |
|-------|-----------|----------------|
| **ผู้ใช้ / เจ้าของฟาร์ม** (`role = 0`) | แอปมือถือ COWSMART | จัดการฟาร์ม โซน และข้อมูลวัวทั้งหมดของตัวเอง ดูราคาตลาด ปรึกษา AI และรายงานปัญหา |
| **ผู้ดูแลระบบ** (`role = 1`) | เว็บแอดมิน | จัดการข้อมูลพื้นฐาน ผู้ใช้ ประกาศแจ้งเตือน ฐานความรู้ AI ราคาตลาด และรายงานปัญหา (เว็บแอดมินอนุญาตเฉพาะบัญชีที่เป็นแอดมิน) |

> ผู้ที่สมัครผ่านแอปจะได้บทบาทผู้ใช้ทั่วไป ถ้าต้องการบัญชีแอดมินและข้อมูลพื้นฐานเริ่มต้น (สายพันธุ์ ประเภทวัว โรค ยา วัคซีน ฯลฯ) สามารถรัน `php artisan db:seed` ในโฟลเดอร์ `api` ได้ (จะสร้างบัญชีแอดมิน `admin@cowsmart.com` รหัสผ่าน `password`) หรือให้แอดมินเปลี่ยนบทบาทให้ในหน้าจัดการผู้ใช้งาน

## 🛠️ เทคโนโลยีที่ใช้

**แอปมือถือ (`cowsmart/`)**
- Flutter (Dart) + Riverpod (จัดการ state) + go_router (นำทาง) + Dio (เรียก API)
- table_calendar, qr_flutter, mobile_scanner (สแกน QR), nfc_manager (NFC), pdf + printing (รายงาน PDF)
- flutter_local_notifications + Firebase Cloud Messaging (แจ้งเตือน), image_picker + flutter_image_compress (รูปภาพ)

**เว็บผู้ดูแลระบบ (`admin-web/`)**
- React 19 + Vite + React Router 7
- Axios, Recharts (กราฟ), lucide-react (ไอคอน)
- Deploy บน Vercel

**ระบบหลังบ้าน (`api/`)**
- PHP 8.2+ และ Laravel 12, Laravel Sanctum (Token Authentication)
- MySQL (ตามคู่มือติดตั้งด้านล่าง)
- Deploy บน Render ด้วย Docker (`Dockerfile`)

**บริการภายนอกที่เชื่อมต่อ** (ตั้งค่าในไฟล์ `api/.env` หากต้องการใช้งาน)

| บริการ | ใช้ทำอะไร | ตัวแปรใน `.env` |
|--------|----------|----------------|
| Cloudinary | เก็บรูปภาพ | `CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`, `CLOUDINARY_API_SECRET` |
| Google Gemini | AI หมอวัว และอ่านราคาจากรูปภาพ | `GEMINI_API_KEY` |
| Brevo | ส่งอีเมล OTP สำหรับรีเซ็ตรหัสผ่าน | `BREVO_API_KEY`, `BREVO_SENDER_EMAIL`, `BREVO_SENDER_NAME` |
| Firebase Cloud Messaging | Push Notification | `FIREBASE_CREDENTIALS` (หรือไฟล์ `storage/app/firebase/service-account.json`) |
| NABC AgriAPI | ราคาตลาดกลางโคเนื้อรายสัปดาห์ | – |

## 🚀 วิธีการติดตั้งและรันโปรเจกต์ (Setup Guide)

### 1. การตั้งค่าระบบหลังบ้าน (API / Backend)

ระบบ API สร้างด้วยเฟรมเวิร์ก Laravel ทำหน้าที่จัดการฐานข้อมูลและลอจิกทั้งหมด

1. เปิดเทอร์มินัลเข้าไปที่โฟลเดอร์ `api`:
   ```bash
   cd api
   ```
2. ติดตั้งไลบรารีที่จำเป็นผ่าน Composer:
   ```bash
   composer install
   ```
3. คัดลอกไฟล์ตั้งค่า Environment:
   ```bash
   cp .env.example .env
   ```
4. สร้าง Application Key:
   ```bash
   php artisan key:generate
   ```
5. **ตั้งค่าฐานข้อมูล:**
   - เปิดโปรแกรมจัดการฐานข้อมูล (เช่น phpMyAdmin หรือ TablePlus) สร้าง Database ใหม่ชื่อ `COWSMART`
   - เปิดไฟล์ `.env` ที่เพิ่งสร้างขึ้น และแก้ไขค่าให้ตรงกับฐานข้อมูลของคุณ:
     ```env
     DB_CONNECTION=mysql
     DB_HOST=127.0.0.1
     DB_PORT=3306
     DB_DATABASE=cowsmart
     DB_USERNAME=root
     DB_PASSWORD=
     ```
6. สร้างตารางในฐานข้อมูล (Migrate):
   ```bash
   php artisan migrate
   ```
7. สร้างโฟลเดอร์ลิงก์สำหรับเก็บรูปภาพอัปโหลด:
   ```bash
   php artisan storage:link
   ```
8. สั่งรันเซิร์ฟเวอร์ API:
   ```bash
   php artisan serve
   ```
   _เซิร์ฟเวอร์จะรันอยู่ที่ `http://localhost:8000` (ให้เปิดทิ้งไว้)_

### 2. การตั้งค่าเว็บผู้ดูแลระบบ (Admin Web / Frontend)

ระบบจัดการฟาร์มสำหรับแอดมิน สร้างด้วย React + Vite

1. เปิดเทอร์มินัล (หน้าต่างใหม่) เข้าไปที่โฟลเดอร์ `admin-web`:
   ```bash
   cd admin-web
   ```
2. ติดตั้งไลบรารีที่จำเป็นผ่าน npm:
   ```bash
   npm install
   ```
3. ตรวจสอบไฟล์ `.env` (ถ้ามี) ให้แน่ใจว่า API URL ชี้ไปที่ `http://localhost:8000` (หรือ URL ของเซิร์ฟเวอร์จริง)
4. สั่งรันระบบเว็บแอดมิน:
   ```bash
   npm run dev
   ```
   _ระบบจะแสดง URL บนเทอร์มินัล (เช่น `http://localhost:5173`) ให้คลิกเพื่อเปิดบนเบราว์เซอร์_

### 3. การตั้งค่าแอปพลิเคชันมือถือ (COWSMART / Mobile App)

แอปสำหรับผู้ใช้งานทั่วไป (เจ้าของฟาร์ม) สร้างด้วย Flutter

1. เปิดเทอร์มินัล (หน้าต่างใหม่) เข้าไปที่โฟลเดอร์ `COWSMART`:
   ```bash
   cd COWSMART
   ```
2. ติดตั้งแพ็กเกจที่จำเป็นสำหรับ Flutter:
   ```bash
   flutter pub get
   ```
3. **การตั้งค่า API URL:**
   - ตรวจสอบไฟล์ตั้งค่าเครือข่าย เช่น `lib/core/network/api_client.dart` หรือตำแหน่งที่มีการตั้งค่า Base URL
   - หากรันทดสอบบน Emulator (Android) และใช้เซิร์ฟเวอร์ในเครื่อง ให้ตั้ง URL เป็น `http://10.0.2.2:8000`
   - หากรันทดสอบบนอุปกรณ์จริง (เสียบสาย) ตรวจสอบให้แน่ใจว่ามือถือต่อ Wi-Fi วงเดียวกับคอมพิวเตอร์ และเปลี่ยน URL เป็น IP ของเครื่องคอมพิวเตอร์ (เช่น `http://192.168.1.x:8000`)
   - _หมายเหตุ: หากคุณใช้เซิร์ฟเวอร์ที่ออนไลน์แล้ว (เช่น Render) ก็สามารถใช้ URL ของ Render ได้เลย_
4. สั่งรันแอปพลิเคชัน:
   ```bash
   flutter run
   ```
   _ตรวจสอบให้แน่ใจว่าเปิด Emulator หรือเชื่อมต่อโทรศัพท์มือถือเรียบร้อยแล้ว_

## 📝 ข้อมูลเพิ่มเติม (Notes)

- การอัปโหลดรูปภาพในระบบจะมีการบันทึกลงใน **Cloudinary** (ตั้งค่า API Keys ในไฟล์ `.env` ฝั่ง `api` หากจำเป็น) หรือเซฟลง Storage ภายใน
- แอป Flutter มีการใช้งาน `flutter_image_compress` ในการบีบอัดรูปภาพก่อนอัปโหลด ซึ่งต้องการการรันแบบ Full Restart (`flutter run`) เมื่อมีการเพิ่มหรือแก้ไขแพ็กเกจนี้
